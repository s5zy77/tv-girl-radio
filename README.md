# 📻 TV Girl Radio: An A–Z Broadcast

A visual, interactive discography browser for **TV Girl**. This web application allows users to tune into the band's extensive catalog through an alphabetized interface.

---

## 📡 Features

* **Interactive A–Z Grid:** Custom-designed buttons using script typography.
* **Integrated Spotify Player:** Seamlessly listen to tracks as you browse.
* **Immersive Visuals:** High-contrast pink and blue duotone art.

## 🛠️ Tech Stack

* **Hosting:** GitHub Pages
* **Layout:** CSS Grid 
* **Audio:** Spotify Web API Embeds

---

## 🎵 How It Works

1. **Select a Letter:** Click any letter from the central hub.
2. **Play:** Use the media player to stream the selection.
